# NFL Scoreboard

A shareable, live NFL scoreboard. Scores come from ESPN's public scoreboard API and refresh automatically.

Open the GitHub Pages site: <https://lowcutkilt.github.io/nfl-scoreboard/>

This page is a standalone copy of the NFL scores view. It has no fantasy-league data and no home-network details.

## Update the page

Edit `index.html` and push the change to the `main` branch. GitHub Pages publishes from the root of `main`, so the live site updates after the Pages deploy finishes (usually a minute or two).
